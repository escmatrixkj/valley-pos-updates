# Valley POS updates

Official Android APK downloads for Valley POS.

Get the APK from [Releases](https://github.com/escmatrixkj/valley-pos-updates/releases/latest). Future updates can be checked manually in Settings > App Updates.

The stable [update manifest](https://github.com/escmatrixkj/valley-pos-updates/releases/latest/download/latest.json) identifies the exact APK and checksum for the latest release.

This repository contains distribution information only. Application source code, signing keys, credentials and POS data are not stored here.
